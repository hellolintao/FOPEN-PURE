# 赛事详情模块顺序调整设计

## 目标

统一赛事详情页在“报名”“查看赛程”“赛果”状态下的内容顺序，让用户先看到赛事结论和安排，再查看签表、参赛人员与积分规则。

## 页面顺序

赛事详情页主体按以下顺序渲染：

1. 阶段条
2. 标题与基本信息
3. 赛果
4. 赛程
5. 签表（仅小组淘汰赛）
6. 参赛人员
7. 积分规则
8. 删除入口（仅管理员）

未满足现有显示条件的模块继续隐藏，其余可见模块保持上述相对顺序。

## 实现范围

- 仅移动 `miniprogram/pages/tournament-detail/index.wxml` 中现有模块，不复制模块。
- 保留各模块原有 `wx:if`、事件、数据绑定和内部结构。
- 按新顺序同步调整模块入场动画延迟。
- 不修改赛事状态计算、报名流程、赛程/赛果数据或权限逻辑。

## 验证

先更新现有 WXML 顺序回归测试并确认它因旧顺序失败，再移动模块使测试通过。随后运行赛事详情页完整 Jest 测试，确认现有状态与交互逻辑未回归。
