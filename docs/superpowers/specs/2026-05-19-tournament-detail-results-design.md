# 赛事详情页赛果展示与顺序调整 — 设计文档

- 日期：2026-05-19
- 范围：赛事详情页内容顺序、已结算赛果展示、积分规则位置
- 状态：用户已确认，待写实施计划

## 1. 背景与目标

当前 `pages/tournament-detail/index` 已经是主要赛事详情页，并会读取 `match-results.listByTournament` 来辅助判断赛事是否已结算，但页面尚未直接展示赛果。当前内容顺序为：

1. 赛事头部信息
2. 积分规则
3. 赛程
4. 参赛人员
5. 管理员删除赛事

用户希望：

- 将积分规则移到页面下方。
- 比赛结算并保存后，在详情页展示赛果。
- 赛果位置在赛程上方。
- 删除赛事仍保持在页面最后。

## 2. 范围

### 范围内

- 调整 `tournament-detail` 页面内容顺序。
- 在赛事完整结算后展示“赛果 · RESULTS”区块。
- 赛果展示正式结果摘要和每场比分明细。
- 复用现有 `match-results.listByTournament` 数据，不新增云函数接口。
- 补充对应前端单元测试。

### 范围外

- 不改成绩录入页的录分流程。
- 不新增或调整云函数业务接口。
- 不改变比赛结算、积分写入、名次积分计算逻辑。
- 不展示进行中的部分赛果。
- 不删除旧页面或重构详情页整体视觉风格。

## 3. 页面顺序

调整后的详情页内容顺序：

1. 赛事头部信息
2. 已结算赛果
3. 赛程
4. 参赛人员
5. 积分规则
6. 管理员删除赛事

“赛果”区只在赛事完整结算后显示；未结算时不展示占位和空态，避免用户误以为部分成绩是最终结果。

“积分规则”移动到参赛人员之后、删除赛事之前。删除赛事是管理员危险操作，仍保持页面最后。

## 4. 赛果展示规则

### 4.1 显示条件

详情页基于 `match_results` 计算可比赛场：

- 排除 `bye`。
- 排除缺少 `player1` 或 `player2` 的行。
- 排除缺少有效选手 id 的行。

只有满足以下条件才展示赛果：

- 可比赛场数量大于 0。
- 所有可比赛场的 `resultStatus` 都是 `confirmed`。

如果赛事状态已标记为 `completed`，但 `match_results` 里仍有未确认可比赛场，页面以 `match_results` 为准，不展示最终赛果。

### 4.2 摘要内容

赛果区标题为“赛果 · RESULTS”。

摘要层展示：

- 已完成场次：`已完成 X / X 场`
- 淘汰赛：突出冠军、亚军；如数据不足则只展示可推导出的名次。
- 常规赛：突出胜场或积分靠前的选手/组合。

常规赛排名优先级：

1. 赛事内积分合计高者靠前。
2. 胜场多者靠前。
3. 负场少者靠前。
4. 名称字典序兜底，保证排序稳定。

### 4.3 明细内容

明细按轮次分组展示，每场包含：

- 轮次
- 双方选手或组合
- 比分
- 胜方
- 本场积分变化

双打以组合形式展示，例如 `A / B` 对 `C / D`。

比分沿用成绩页格式：

- 普通比分：`4:2`
- 抢七比分：`3:3 (7-5)`

如果某场缺少 `pointsAwarded`，该场不展示积分变化，只展示比分和胜方。页面不根据积分规则临时推导积分，避免和云端落库结果不一致。

## 5. 数据流

`tournament-detail` 当前已有 `loadResultSummary()`，会调用：

```js
wx.cloud.callFunction({
  name: 'match-results',
  data: { action: 'listByTournament', tournamentId }
})
```

本次调整继续复用该调用，并将返回的 `match_results` 加工成两个页面数据：

- `resultSummary`：继续服务赛事状态与按钮文案。
- `resultDisplay`：服务赛果区展示。

`resultDisplay` 建议结构：

```js
{
  visible: true,
  completedText: '已完成 6 / 6 场',
  leaders: [],
  groups: [
    {
      round: 1,
      label: 'ROUND 01',
      matches: []
    }
  ]
}
```

`refresh()` 已在 `onShow()` 调用，因此管理员从成绩页完成“确认和保存比赛”返回详情页后，详情页会自动重新拉取结果并展示赛果。

## 6. 边界与状态

- 可比赛场数量为 0：不展示赛果。
- 还有待录入或待确认比赛：不展示赛果。
- 全部可比赛场已确认：展示完整赛果。
- `pointsAwarded` 缺失：该场隐藏积分变化。
- 后续管理员改分导致下游轮次被清空或赛事回到进行中：刷新后隐藏最终赛果。
- 非参赛会员可查看已结算赛果；这与当前已结算赛事允许查看成绩页的权限保持一致。
- 自由拉球不属于正式比赛，不进入赛果。
